# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short version: be kind, be patient, assume good faith, attack problems
rather than people. Harassment, gatekeeping, and sustained hostility get one
warning, then removal.

Conduct concerns: open an issue if you're comfortable doing so publicly, or
email the maintainer (see the GitHub profile).
